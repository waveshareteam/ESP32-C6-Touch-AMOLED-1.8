# 持续集成

[English](CI.md)

Build Examples 工作流会在每个 PR 上始终显示轻量路由和 Markdown 门禁；产品编译与固件打包仅在门禁通过并且选中示例后运行。

## 矩阵

| 范围 | 版本 | 第一方工程 | 构建任务 |
| --- | --- | ---: | ---: |

| ESP-IDF | v6.0.2 | 7 | 7 |

| Arduino V2 | 3.3.11 | 9 | 9 |

完整 `all`、tag 或手动运行共安排 37 个固件构建。

## 路由

`scripts/discover_examples.py` 接受 `all`、示例名称或仓库相对路径。仅文档 PR 只运行轻量门禁并选择 0 个产品构建；直接示例源码只选择对应工程或草图。工作流、配置、打包和发现输入选择相应完整范围；Arduino 捆绑库源码选择草图，库 Markdown 不构建。

重命名和删除会检查旧路径。`Firmware/` 的 Markdown、源码、二进制和归档会单独报告，且不进入 examples 矩阵。缺失或空 diff 会失败，不会静默回退到全部构建；未知的完整非文档路径保守选择完整矩阵。

本地产品构建不属于仓库 CI 契约；工作流是构建验证范围。
